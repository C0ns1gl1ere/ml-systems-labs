# Image-Based Classification of Military Vehicles Using a Lightweight Neural Network

## Dataset

[Military and Civilian Vehicles Classification, version 1](https://data.mendeley.com/datasets/njdjkbxdpn/1) by Gupta et al. The full dataset contains 6,772 images and is licensed under CC BY 4.0. The project will use four classes: military tank, military truck, military aircraft, and military helicopter.
