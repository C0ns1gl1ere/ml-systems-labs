# Lab 4: UCI Adult - готовий проєкт

Почни з **REPORT.md**: це англомовний звіт з постановкою задачі, перевірками та
реальними результатами запуску. Усі налаштування лежать у `config.yaml`.

## Запуск

Відкрий PowerShell у цій папці й виконай одну команду:

```powershell
.\run_lab.ps1
```

Потрібен Python 3.11. Скрипт створить окреме середовище, встановить зафіксовані бібліотеки й
виконає лабораторну. Якщо політика PowerShell забороняє запуск скриптів, можна
використати звичайний варіант (без зміни політики комп'ютера):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Якщо бібліотеки вже встановлені, достатньо `python run.py`.
Для точного повторення перевіреного середовища замість `requirements.txt`
використовуй `requirements-lock.txt`. Перший запуск інсталятора потребує мережі.
Початкові дані включено в архів: повторний запуск обробки не потребує OpenML.
Видалення `data/raw` змусить завантажити їх з OpenML заново.

## Що треба доробити самому

Методичка вимагає **ручної** перевірки 50 рядків. Автоматичний аудит уже
підготовлено, але він не замінює людський перегляд:

1. Відкрий `results/audit_50_manual.csv` в Excel або редакторі таблиць.
2. Зістав кожен рядок із `DATA_DICTIONARY.md`: діапазони, допустимі категорії,
   відповідність education і education-num; `?` означає пропуск.
3. Впиши `REVIEWED_OK` або `FLAGGED` у `human_review_status`, додай примітку.
4. Додай до звіту власний висновок із кількістю перевірених і позначених рядків.
   Не стверджуй, що підтвердив справжній дохід людини: джерело цього не дозволяє.

Перезапуск не перезаписує цей файл. Якщо змінив seed або джерело, збережи попередню
ручну перевірку окремо та підготуй нову вибірку, видаливши старий worksheet.
Для Adult не потрібно чекати 24 години чи рахувати Cohen's kappa: це альтернативна
гілка завдання для суб'єктивних міток.

## Коротко для захисту

- **Чому split перед очищенням?** Щоб тестові дані не впливали на медіани, моди,
  межі обрізання, масштабування або словник категорій.
- **Чому F1 разом з accuracy?** Класи незбалансовані; F1 оцінює precision/recall
  саме для `>50K`. У конфігурації поріг не підбирається за тестом.
- **Що означає 'test untouched'?** Збережені всі початкові рядки та мітки тесту;
  до їхніх ознак застосовуються лише перетворення, навчені на train.
- **Що з дублікатами?** Видаляємо точні записи з train разом із міткою. Окремо
  рахуємо однакові ознаки з різними мітками; не виправляємо їх навмання.
- **Чому нові ознаки можуть не допомогти?** capital_net є лінійною комбінацією
  наявних ознак, а корисність hours_per_age залежить від даних і моделі.
- **Навіщо SHA256?** Щоб перевірити, що отримані оброблені дані ідентичні.
  Сам хеш не доводить правильність даних або відсутність витоку.
- **Обмеження split?** Однакові вектори ознак можуть трапитися в обох частинах.
  Їх кількість показано у звіті; це обмеження заданого випадкового поділу.
